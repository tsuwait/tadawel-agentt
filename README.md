# 📊 نبض تداول — وكيل AI مفتوح المصدر للسوق السعودي

وكيل ذكي يجاوب بالعربي عن أسعار الأسهم السعودية وأدائها التاريخي،
ويفسّر **ليش تحرك السهم اليوم** بالأخبار وإعلانات تداول.

مرخّص MIT · يعمل بلا مفاتيح مدفوعة · يغطي كل أسهم تاسي.

---

## يعمل فوراً

```bash
pip install -r requirements.txt
cp .env.example .env      # ضع مفتاح Claude
python build_universe.py  # يكتشف كل أسهم تاسي (مرة واحدة)
streamlit run app.py
```

---

## تغطية كل أسهم تاسي

قوائم الشركات المكتوبة يدوياً تنقص دائماً — تُدرج شركة جديدة فتختفي من الأداة.
لذلك المشروع **يكتشف الشركات بنفسه**:

```bash
python build_universe.py           # السوق الرئيسي
python build_universe.py --nomu    # يشمل السوق الموازي نمو
```

السكربت يمسح كل أرقام الشركات المحتملة في نطاقات تداول، يتحقق أيها له
بيانات تداول فعلية، يجلب أسماءها، ويحفظها في `tadawul_universe.json`.
التطبيق يستخدم الملف تلقائياً بعدها.

أعد تشغيله كل بضعة أشهر لالتقاط الإدراجات الجديدة.

**حتى بدون تشغيله**، أي رقم رباعي تكتبه يعمل مباشرة، وفيه ١٥٤ شركة
بأسمائها العربية مدمجة للبحث بالاسم.

### إضافة اسم عربي لشركة
افتح `symbols.py` وأضف سطراً في `SEED_NAMES`:

```python
"4009": ("السعودي الألماني الصحية", "Saudi German Health"),
```

## مصادر البيانات — لا اعتماد على مصدر واحد

`providers.py` طبقة تجرّب المزوّدين بالترتيب حتى ينجح أحدهم:

| المزوّد | المفتاح | ملاحظات |
|---|---|---|
| **Yahoo Finance** | لا يحتاج | الافتراضي، يعمل فوراً |
| Twelve Data | `TWELVEDATA_API_KEY` | خطة مجانية تغطي تداول |
| EODHD | `EODHD_API_KEY` | تاريخ عميق |
| FMP | `FMP_API_KEY` | أسعار وقوائم مالية |

أضف أي مفتاح في `.env` ويُستخدم تلقائياً كبديل — بدون تعديل سطر كود.
لو سقط ياهو غداً، المشروع يستمر.

> ⚠️ ياهو مصدر مجاني غير رسمي وشروطه لا تسمح بالاستخدام التجاري.
> للاستخدام الشخصي عادي؛ لأي شيء تجاري استخدم مزوّداً مرخّصاً.

## ما الذي يقدمه

- بحث عن أي سهم بالاسم العربي أو الإنجليزي أو الرقم الرباعي (أرامكو / Aramco / 2222)
- لقطة سعرية كاملة: آخر إغلاق + مقارنة مع 7 فترات زمنية
- أعلى وأدنى سعر خلال سنة، ومتوسط كمية التداول
- أداء السهم بين تاريخين تحددهما أنت
- مقارنة عدة أسهم في نفس الوقت
- رسم بياني تفاعلي لحركة السعر
- محادثة طبيعية بالعربي مع وكيل يستخدم الأدوات ولا يخترع أرقاماً

## التنصيب

### 1) نزّل المتطلبات

```bash
cd tadawul-agent
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### 2) حط مفتاح Claude

احصل على مفتاح من <https://console.anthropic.com> ثم:

```bash
cp .env.example .env
```

وافتح `.env` وحط المفتاح:

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
```

### 3) شغّل

**واجهة الويب (الأفضل):**

```bash
streamlit run app.py
```

بيفتح على `http://localhost:8501`

**واجهة الطرفية:**

```bash
python agent.py
```

**اختبار طبقة البيانات لحالها (بدون مفتاح API):**

```bash
python tadawul_data.py
```

## مصدر البيانات

المشروع يستخدم **Yahoo Finance** عبر مكتبة `yfinance`. رموز السوق السعودي
عندهم بصيغة `<الرقم>.SR` — مثلاً `2222.SR` لأرامكو، و `^TASI.SR` للمؤشر العام.

**أشياء لازم تعرفها:**

- الأسعار قد تتأخر حتى ١٥ دقيقة عن السوق الفعلي
- ياهو مصدر مجاني غير رسمي، وممكن ينقطع أو يغيّر شكل البيانات
- الشركات المدرجة حديثاً أو أسهم "نمو" قد لا تكون كلها مغطاة

**لو احتجت بيانات لحظية أو رسمية**، غيّر دوال `get_history` و `get_profile`
في `tadawul_data.py` فقط — باقي المشروع ما يتأثر. بدائل مدفوعة:

| المزود | ملاحظات |
|---|---|
| Twelve Data | يغطي تداول، خطة مجانية محدودة |
| EODHD | تاريخي عميق وبيانات نهاية اليوم |
| Financial Modeling Prep | قوائم مالية + أسعار |
| Refinitiv / LSEG | مستوى مؤسسي، مكلف |
| موزّعو تداول المعتمدون | البيانات الرسمية اللحظية |

## تخصيصات مقترحة

- **إضافة شركات:** زد سطر في قاموس `SYMBOLS` داخل `tadawul_data.py`
- **إضافة مؤشرات فنية:** أضف دالة (RSI، متوسطات متحركة) في `tadawul_data.py`
  ثم عرّفها كأداة جديدة في `tools.py` — الوكيل بيبدأ يستخدمها تلقائياً
- **تنبيهات:** شغّل `get_snapshot` بجدولة (cron) وأرسل تنبيه عند تجاوز سعر معين
- **بوت واتساب/تيليجرام:** استبدل `app.py` بمعالج رسائل ينادي `TadawulAgent.chat()`
- **موديل أقوى:** غيّر `CLAUDE_MODEL` في `.env` إلى `claude-opus-5`

## 🆕 ميزة "ليش تحرك السهم؟"

الميزة الأساسية في المشروع. تشتغل على أربع خطوات مرتبة:

**١) الأرقام أولاً** — `market_pulse.py` يحسب من البيانات الفعلية:
نسبة التغير، فجوة الافتتاح، المدى اليومي، حجم التداول مقابل متوسط ٣ أشهر،
والموقع من نطاق ٥٢ أسبوعاً.

**٢) السياق قبل البحث** — يقارن حركة السهم بحركة تاسي في نفس الجلسة:
- السوق كله نازل؟ → الحركة عامة، ما فيه داعي نفتش عن سبب خاص
- السهم عكس السوق؟ → غالباً سبب خاص بالشركة
- حجم التداول ضِعف المعتاد؟ → فيه شيء حصل، ابحث بجدية

**٣) البحث** — الوكيل يبحث في الويب عن أخبار الشركة وإعلانات تداول
في آخر ثلاثة أيام، من أرقام ومباشر والاقتصادية وموقع تداول.

**٤) الحكم بثقة معلنة** — كل جواب ينتهي بدرجة ثقة:

| | |
|---|---|
| 🟢 مؤكد | إعلان رسمي أو خبر مباشر يفسّر الحركة |
| 🟡 مرجّح | خبر ذو صلة لكن الربط غير مؤكد |
| 🔴 غير معروف | ما فيه سبب واضح |

### القاعدة التي تحمي الأداة من نفسها

الوكيل مُلزَم يقول **"ما لقيت خبراً يفسّر الحركة"** إذا ما لقى.
اختلاق تفسير مقنع لكنه خاطئ أخطر من الاعتراف بعدم المعرفة، لأن القارئ
ممكن يبني عليه قراراً. والأسواق فعلاً تتحرك أحياناً بلا سبب معلن.

كذلك: **كل الحسابات تتم في الكود، لا في الموديل.** الموديل يشرح ويربط
بالأخبار فقط. النِسب والفروق والمتوسطات كلها من `market_pulse.py`.
